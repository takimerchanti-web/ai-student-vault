# Mohammad Vault – PWABuilder Package

Upload this folder or its hosted URL to PWABuilder.

- `index.html` – complete single-file app
- `public/manifest.json` – static install manifest
- `public/sw.js` – offline service worker
- `public/icon-192.png` / `public/icon-512.png` – install icons

For a hosted PWABuilder scan, deploy the folder so `manifest.json` is reachable at the same path as the app. The circuit simulator buttons open Tinkercad and Logic.ly online; the C Lab and PPT Studio work offline.
